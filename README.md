# CarePoint — Healthcare Appointment & Patient Portal

## Features
- Responsive navigation: Home, Patient Registration, Appointments, Health Information, Services, Technologies
- Patient registration form with HTML5 validation
- Appointment table with generated appointment IDs and Pending status
- Health information cards updated after registration
- Bootstrap 5 layout and custom CSS styling

## Run the project
1. Extract the ZIP file.
2. Open the `healthcare_portal_project` folder in VS Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.
4. An internet connection is needed to load Bootstrap and Google Fonts CDN assets.

## Files
- `index.html` — page structure and form
- `style.css` — custom styling
- `script.js` — form validation and front-end interactions

## Note
This is a front-end demonstration. Appointment records exist only in the current page session and are not saved to a database. Doctor names and appointment statuses are sample data.
