🏥 Healthcare Appointment & Patient Portal

A responsive Healthcare Appointment & Patient Portal built using HTML5, CSS3, Bootstrap 5, and JavaScript. This project helps patients register their details, book appointments, view appointment records, and access health information through a simple and user-friendly interface.

✨ Features

- 📝 Patient Registration Form with HTML5 validation
- 👤 Personal Information and Medical Details
- 🩺 Department and Doctor Selection
- 📅 Appointment Date and Time Selection
- 📋 Appointment Table with Appointment ID and Status
- 💊 Health Information Dashboard
- 🏥 Healthcare Services Section
- 📱 Responsive Navigation Bar and UI
- 🔄 Register and Reset Form Buttons

🛠️ Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- JavaScript

🚀 How to Run

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open "index.html".
4. Run the project using Live Server.
5. Register a patient and explore the appointment and health information sections.
